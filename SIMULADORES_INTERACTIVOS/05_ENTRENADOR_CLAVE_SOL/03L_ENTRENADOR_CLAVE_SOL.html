¿Por qué Safari no detecta tu teclado Akai / Korg?
Apple Safari en macOS no soporta la API Web MIDI para dispositivos USB físicos por decisión de Apple.

✅ Solución recomendada (100% Plug & Play):
Abre este archivo en Google Chrome o Microsoft Edge. Ambos reconocen instantáneamente tu Akai LPK25 o teclado Korg sin instalar ningún driver ni configurar nada.

⌨️ También puedes usar el teclado de tu Mac ahora mismo:
Usa las teclas A (Do4), S (Re4), D (Mi4), F (Fa4), G (Sol4), H (La4), J (Si4), K (Do5).
