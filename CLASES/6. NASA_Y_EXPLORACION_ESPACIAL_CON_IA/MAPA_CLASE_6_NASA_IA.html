🤖 ¿Qué es un Agente de Inteligencia Artificial?

A diferencia de un modelo de lenguaje convencional que únicamente responde con texto a preguntas aisladas, un Agente de IA es un sistema computacional autónomo dotado de capacidad para percibir su entorno, tomar decisiones lógicas, accionar herramientas externas reales y aprender de sus propios resultados en un ciclo de retroalimentación continuo.

🔄 Bucle Continuo de Autocorrección: El resultado de la acción se evalúa, se aprende y se convierte en la nueva percepción del siguiente ciclo.
Fase 1 • Entrada 👁️

PERCIBIR (Percepción / Observar)

Recibe información de su entorno (sensores, preguntas del usuario, documentos, APIs o estados del sistema).
¿Cómo se aplica en este curso?: El agente lee el prompt redactado por los alumnos, inspecciona la estructura de carpetas en iCloud Drive, consulta la telemetría en tiempo real de la NASA y detecta el estado del navegador o servidor.
Fase 2 • Cognición 🧠

RAZONAR (Pensar / Planificar)

Analiza el objetivo, evalúa opciones lógicas y desglosa la tarea en una secuencia ordenada de pasos.
¿Cómo se aplica en este curso?: Diseña la arquitectura web, selecciona Three.js descartando motores inadecuados, planifica la posición fija del panel HUD a la derecha y programa las funciones de navegación orbital.
Fase 3 • Intervención 🛠️

ACTUAR (Acción / Ejecutar)

Utiliza herramientas externas (ejecutar código, buscar en la web, enviar comandos o modificar archivos) para cambiar el entorno.
¿Cómo se aplica en este curso?: Escribe directamente el código del simulador en el archivo HTML, ejecuta comandos en la terminal de macOS, lanza servidores web locales y actualiza libros de cálculo en Excel mediante AppleScript.
Fase 4 • Memoria 💾

APRENDER (Memoria / Reflexionar)

Evalúa el resultado de su acción, almacena lo aprendido en su contexto o base de datos y se autocorrige para el siguiente ciclo.
¿Cómo se aplica en este curso?: Verifica que ningún enlace esté roto, guarda el nuevo estado en el archivo vivo ESTADO_GLOBAL_PROYECTOS.md y aprende reglas de no-repetición para futuras sesiones formativas.

⚖️ Comparativa Didáctica: Chatbot Clásico vs. Agente de IA Moderno

💬 Chatbot Clásico (ChatGPT / Gemini básico)

  • Solo emite texto en una caja de chat aislada.
  • No puede tocar tus archivos ni ver las carpetas del ordenador.
  • Si el código tiene un fallo, el usuario debe copiarlo, probarlo y depurarlo manualmente.
  • Olvida el estado de la tarea en cuanto la ventana se cierra o satura.

🚀 Agente Autónomo (Antigravity)

  • Tiene «ojos y manos» sobre el sistema de archivos y las herramientas del sistema operativo.
  • Crea, edita y sincroniza aplicaciones web completas en segundo plano.
  • Autocomprueba y verifica que los botones y enlaces 3D funcionen antes de entregar la tarea.
  • Mantiene memoria persistente mediante documentos vivos de conocimiento (AGENTS.md y GEMINI.md).
Concepto 1 de 6 • Fundamentos de Agentes

⚡ Antigravity: Agente Autónomo con Acceso Real a Ficheros

En este curso no programamos simuladores copiando y pegando manualmente fragmentos de código sueltos. Utilizamos Antigravity, el entorno de desarrollo agéntico de Google DeepMind que dota a la inteligencia artificial de herramientas nativas para inspeccionar el disco duro, modificar archivos en caliente, ejecutar procesos de sistema y persistir su aprendizaje a través de reglas vivas.

📂

1. Acceso y Modificación Quirúrgica de Ficheros

Antigravity cuenta con herramientas de sistema integradas para leer (read_file), editar porciones exactas sin romper el resto (edit_file) y crear nuevas aplicaciones (write_file). Esto permite modificar este mismo archivo HTML o los simuladores 3D en tiempo real dentro de iCloud Drive.

read_file → edit_file → write_file (Cero copia-pega manual)
📜

2. Directivas Vivas: AGENTS.md y GEMINI.md

En la raíz del proyecto residen los archivos de directivas de gobernanza (AGENTS.md y GEMINI.md). Son las "Leyes de la Robótica" que el agente consulta de forma obligatoria al despertar: el Protocolo Cero Submits (cero interrupciones interactivas), el estándar de fichas flotantes a la derecha y la prohibición de generar imágenes falsas de IA en astronomía.

AGENTS.md & GEMINI.md → Protocolo de Oro & Estándares Visuales
🧠

3. Memoria Persistente: ESTADO_GLOBAL_PROYECTOS.md

Las ventanas de chat de los modelos tradicionales son efímeras y sufren amnesia. Para resolverlo, Antigravity actualiza continuamente un documento vivo centralizado (ESTADO_GLOBAL_PROYECTOS.md) con el estado de las 60 sesiones de IA, los 8 bloques de robótica, los contadores correlativos ([COMANDO 56]) y el módulo musical Web MIDI.

Frase de Herencia Universal → Cambio de chat sin pérdida de contexto
🛠️

4. Automatización Nativa macOS y Servidores Wi-Fi

El agente se comunica con el sistema operativo sin requerir librerías pesadas: controla Microsoft Excel mediante AppleScript nativo para evitar bloqueos de archivos, levanta servidores HTTP locales (python3 -m http.server 8888) en segundo plano para ver partituras en el iPad y publica cambios en GitHub Pages.

AppleScript + Sandbox seguro + Sincronización GitHub desatendida
